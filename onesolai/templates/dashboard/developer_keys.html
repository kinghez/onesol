How to Use OneSol Developer API & AI Agents

• Public Key (pk_live_...): Safe to use in frontend scripts or public widgets. Allows querying live tools, stock levels, and pricing.

• Secret Key (sk_live_...): Keep this key secure on your backend server. Required for purchasing tools with your wallet balance and managing user orders.

• AutomateSocial / Custom Chatbots: Pass your key in the header Authorization: Bearer sk_live_... or X-Agent-Secret: onesol_agent_secret_2026 when configuring AI Studio tools.

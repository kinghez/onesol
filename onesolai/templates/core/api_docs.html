Base URL

All REST API endpoints are served over HTTPS under the following base URL:

https://onesolai.com/api/v1/

Authentication

Authenticate your API requests by sending your API Key in an HTTP Header:

Authorization: Bearer sk_live_your_secret_key_here

Or using custom header: X-API-KEY: sk_live_...

Public Key (pk_live_...)

Read-only access. Used to query tools, check stock levels, and view pricing.

Secret Key (sk_live_...)

Full access. Required to purchase tools, check user profile, and initiate wallet top-ups.

Rate Limiting

API requests are capped at 60 requests per minute per API key. Exceeding this limit returns HTTP 429 Too Many Requests with a Retry-After: 60 header.

GET /api/v1/tools/

List active AI tools with live prices in NGN/USD and stock availability.

Query Parameters:

  • query (optional string): Search keyword e.g. chatgpt
  • category (optional string): Category slug e.g. ai-chatbots

Example Response (200 OK):

{ "success": true, "count": 1, "tools": [ { "id": 60, "name": "CapCut Pro 30 Days", "slug": "capcut-pro-30-days-1", "category": "Video Creation", "price_ngn": 9103.04, "price_usd": 6.67, "is_in_stock": true, "short_description": "Unlock premium video editing features with CapCut Pro for 30 days.", "detail_url": "https://onesolai.com/tools/capcut-pro-30-days-1/" } ] }
POST /api/v1/orders/buy/

Purchase an AI tool using your wallet balance. Triggers instant vendor fulfillment and returns activation details.

Request Body (JSON):

{ "tool_id": 60, "delivery_email": "user@example.com" }

Example Response (200 OK):

{ "success": true, "message": "Successfully purchased CapCut Pro 30 Days! Order #ORD-849201 processed.", "order": { "id": 142, "order_number": "ORD-849201", "tool_name": "CapCut Pro 30 Days", "amount_paid_ngn": 9103.04, "delivery_email": "user@example.com", "access_details": "Login Email: user@vip.com | Pass: CapCut2026! | Activation Link: https://..." } }
POST /api/v1/wallet/topup/

Initiates a Paystack checkout transaction to credit your wallet balance.

Request Body (JSON):

{ "amount_ngn": 5000 }

Example Response (200 OK):

{ "success": true, "reference": "WAPI_a1b2c3d4", "amount_ngn": 5000.0, "authorization_url": "https://checkout.paystack.com/39a01fd..." }

Fulfillment Webhooks

Configure your Webhook URL in your Developer Dashboard. Whenever an order is completed, OneSol AI sends an HTTP POST request to your endpoint.

Webhook Payload:

{ "event": "order.fulfilled", "order_id": 142, "order_number": "ORD-849201", "tool_name": "CapCut Pro 30 Days", "delivery_email": "user@example.com", "access_details": "Login Email: ...", "total_amount_ngn": 9103.04, "fulfilled_at": "2026-08-04T17:00:00Z" }

Signature Verification Header:

X-OneSol-Signature: t=1722790800,v1=9f8a... (HMAC SHA256)
